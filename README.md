# V2V — 实时中英游戏语音翻译

> 消费级、端到端、实时中英语音翻译。首批场景：**多人 FPS 游戏**（Valorant / CS）。
> 本笔记库是项目的**设计与状态中心**。代码与数据在美西服务器上运行。

## 项目状态：Phase 1 前半段管线已跑通 ✅

```
YouTube 开黑视频 → yt-dlp 采集 → ffmpeg 预清洗 → FunASR+SenseVoice → 文字
   (职业战队队内语音)  (M1)         (M2 清洗)        (M2 ASR, 28x实时)    ✅打通
```

- 数据：7 个 Valorant 开黑视频 / 4.9 小时音频 / 清洗后 539MB（16k单声道）
- ASR：CPU 28x 实时转写，内存峰值 3.5GB / CPU 利用 1.5核（**瓶颈是 CPU 不是内存**）
- 转写内容验证为真实战队战术语音（smokes / tap and go through / hit for 80 等）

> ⚠️ **技术路线已更新（2026-08-24 起，08-29 再修）**：旧版"Phase 1 只做 S2TT / TTS 造音对 / LLM 造中英配对台账"已推翻。

## 关键决策（已锁定，2026-08-24 起；08-29 再修）

- **架构**：多模态端到端（音/字 输入 × 音/字 输出 四象限）；**不接受**部署期 STT→MT→TTS 级联
- **训练方法**（2026-08-29 修正，推翻"TTS 造音对"和"LLM 造中英配对台账"）：**不逐字求完美中英配对**（现实本就几乎没真实双语语音对）。训练**主力 = 直接喂纯英+纯中的真实开黑视频音频**；**微调现成双端端到端底座**，不从零训，学到 FPS 黑话窄域（报点/嘲讽/混音造腔）。
- **LLM 只做辅助**（不全权）：采集/数据层自动打"游戏/内容类型"标签、生成难例、做评估。**标签最终你人工把关**。
- **为什么不配对齐**：真实"同一句中英双语音"的视频几乎不存在（见调研/数据获取），硬 LLM 凑对只成播乱码。故不追配对。
- **说话人分离**：不做；FPS 多人重叠，按**段级战术意群块**处理
- **数据**：游戏优先，FPS 开黑语音（搜索命门词 `comms`/`team voice`）；排除电竞解说；**分类在采集时就判断**（你+LLM辅助）
- **采集**：只抓点播/回放，不实时录直播；**英文 YouTube 与中文 B站 并行启动**
- **ASR**：自跑 CPU，用 SenseVoice（中文优、嘈杂鲁棒、自带事件检测），转段级文字
